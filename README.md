# ServGui - Loja de Bebidas

Projeto desenvolvido para a atividade "Evoluindo a Loja Simples".

## Funcionalidades

- Cadastro de bebidas.
- Edição de produtos sem criar item duplicado.
- Remoção individual de produtos.
- Contador de produtos cadastrados.
- Mensagem quando a lista está vazia.
- Validação para impedir quantidade igual ou menor que zero.
- Validação básica de nome e preço.
- Footer.
- Layout responsivo.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro

Os produtos existem somente enquanto a página estiver aberta. Não foi utilizado banco de dados, API, framework ou armazenamento permanente.
